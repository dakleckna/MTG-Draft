# Draft Reviewer

## Neue Sets

Der Button **Neue Drafts suchen** lädt die aktuell veröffentlichte Liste aus
`drafts.json`. Ein GitHub-Workflow aktualisiert diese Datei täglich um 06:17 UTC
aus den Draftsim-Reviews und den Setdaten von Scryfall. Er kann auf GitHub auch
über **Actions → Update draft reviews → Run workflow** sofort gestartet werden.
